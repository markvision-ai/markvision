### 2. 📅 DatePicker (Calendar Fix)

**Проблема**: Дублирующиеся кнопки "Сегодня", "Вчера", "7 дней"
**Решение**: Объединены в одну панель управления + добавлен DatePicker

#### Новая панель управления:
```tsx
<div className="flex flex-col sm:flex-row items-start sm:items-center gap-3 p-3 sm:p-4 bg-muted/50 dark:bg-card/50 rounded-lg border border-border">
  {/* Quick Date Buttons */}
  <Button onClick={() => handleQuickDate(0)}>Сегодня</Button>
  <Button onClick={() => handleQuickDate(1)}>Вчера</Button>
  <Button onClick={() => handleQuickDate(7)}>7 дней</Button>
  <Button onClick={() => handleQuickDate(30)}>30 дней</Button>
  
  {/* Calendar Picker */}
  <Popover>
    <PopoverTrigger asChild>
      <Button variant="outline">
        <CalendarIcon className="mr-2" />
        {format(dateRange.from, 'dd MMM')} - {format(dateRange.to, 'dd MMM yyyy')}
      </Button>
    </PopoverTrigger>
    <PopoverContent>
      <Calendar mode="range" selected={dateRange} onSelect={setDateRange} numberOfMonths={2} />
    </PopoverContent>
  </Popover>
</div>
```

**Функционал**:
- Быстрый выбор периода (Сегодня, Вчера, 7 дней, 30 дней)
- Календарь с выбором произвольного диапазона дат
- Отображение 2 месяцев в календаре
- Локализация на русском языке
- Связано с загрузкой данных через `dateRange` state

### 3. 🖼️ Поддержка изображений

**Проблема**: Загрузчик поддерживал только видео
**Решение**: Добавлена поддержка .jpg, .png, .webp

#### Изменения:
```tsx
accept="image/jpeg,image/jpg,image/png,image/webp,video/*"
```

**Проверка**:
```tsx
const extension = file.name.split('.').pop()?.toLowerCase();
if (isImage && !['jpg', 'jpeg', 'png', 'webp'].includes(extension || '')) {
  toast.error(`${file.name}: поддерживаются только .jpg, .png, .webp`);
  continue;
}
```

**Отображение**:
- Изображения: прямой рендер `<img>`
- Видео: иконка `<Play>` с черным фоном
- Разные иконки для типов (ImageIcon / Video)

### 5. 🔧 Исправление обрезки текста

**Проблема**: Цифры в карточках "Total Spent" превращались в многоточие
**Решение**: 

```tsx
// Было:
<p className="text-base sm:text-xl font-bold truncate">{card.value}</p>

// Стало:
<p className="text-base sm:text-xl font-bold break-words" title={card.value}>
  {card.value}
</p>
```

**Изменения**:
- `truncate` → `break-words` (перенос вместо обрезки)
- Добавлен `title={card.value}` для tooltip
- Цифры полностью видны на всех экранах
