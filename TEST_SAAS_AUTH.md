## 🔧 Отладка

### Проблема: Не работает редирект на /setup

**Решение:**
```sql

SELECT * FROM project_access WHERE user_id = '[USER_ID]';

```

### Проблема: Вижу чужие проекты

**Решение:**
```sql
-- Проверить RLS политики:
SELECT * FROM pg_policies WHERE tablename = 'projects';

-- Должна быть политика проверяющая project_access
```

## 📊 SQL для проверки

### Проверить project_access:
```sql
SELECT 
  pa.user_id,
  u.email,
  p.name as project_name
FROM project_access pa
JOIN auth.users u ON u.id = pa.user_id
JOIN projects p ON p.id = pa.project_id
ORDER BY pa.created_at DESC;
```

### Проверить user_roles:
```sql
SELECT 
  ur.user_id,
  u.email,
  ur.role
FROM user_roles ur
JOIN auth.users u ON u.id = ur.user_id;
```

### Проверить изоляцию:
```sql
-- Для пользователя A:
SELECT COUNT(*) FROM leads 
WHERE project_id IN (
  SELECT project_id FROM project_access 
  WHERE user_id = '[USER_A_ID]'
);

-- Для пользователя B:
SELECT COUNT(*) FROM leads 
WHERE project_id IN (
  SELECT project_id FROM project_access 
  WHERE user_id = '[USER_B_ID]'
);

-- Счетчики должны быть разные!
```
