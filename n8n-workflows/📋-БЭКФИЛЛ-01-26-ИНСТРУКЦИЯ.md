# Бэкфилл 1–26 января 2026

## Что делает код

Код в `📅-BACKFILL-01-26-CODE.js` выдаёт **по одному элементу на каждый день** с **2026-01-01** по **2026-01-26**. Формат такой же, как у «Рассчитать период» в ежедневной связке:  
`yesterday_date`, `yesterday_only_start`, `yesterday_only_end` = конкретный день,  
`period_start` = `2026-01-01`, `period_end` = `2026-01-26`.

Дальше по цепочке для каждого дня идут запросы постов, агрегация и запись в Supabase (`daily_data`, `content_production_stats`).

## Как использовать

1. Открой workflow **Instagram Daily Automation** в n8n.
2. Открой ноду **«📅 Рассчитать период»** (Code).
3. **Скопируй весь код** из `📅-BACKFILL-01-26-CODE.js` и вставь в поле кода (замени текущий код).
4. **Отключи** триггер «⏰ Ежедневно 09:00» (или используй отдельную копию workflow с Manual Trigger).
5. Запусти workflow **вручную** один раз.
6. Проверь, что в Supabase заполнились `daily_data` и `content_production_stats` за каждый день 1–26 января.
7. **Верни** в ноду «📅 Рассчитать период» исходный код «09:00 за вчера» и снова включи расписание.

Дальше используй обычную связку: **каждый день в 09:00** — данные **за вчера**.

## О подписчиках

Блок «👥 Получить подписчиков (сегодня)» и «вчера» завязан на **текущие** данные из API. Для бэкфилла исторических подписчиков за 1–26 января этих данных нет — их нужно либо заполнить вручную в `daily_data`, либо оставить только посты/охваты/комментарии и не трогать подписчиков при бэкфилле.

## Исправления в основной связке (09:00 за вчера)

В `INSTAGRAM-DAILY-AUTOMATION.json` внесены правки:

- **📊 Запрос подписчиков (вчера)** → **🧮 Агрегировать подписчиков** (вход 2); **📅 Рассчитать период** → агрегатор (вход 3).
- **🧮 Агрегировать подписчиков** → **📦 Map daily_data** → **💾 Записать подписчиков в daily_data** (без обхода Map).
- **📦 Map daily_data** → **✅ Финальный лог** (для корректного `followersData`).
- **💾 Сохранить статистику** и **💾 Записать подписчиков** оба идут в **✅ Финальный лог**.
- В **🔗 Получить подписчиков (вчера)** и **🔗 Построить URL постов** — поддержка 1 или N дней (бэкфилл): `$input.all()` + `map`.
- У **📊 Получить посты** включён **alwaysOutputData**, чтобы пустые посты не обрывали выполнение.
