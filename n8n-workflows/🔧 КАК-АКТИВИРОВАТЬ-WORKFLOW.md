# 🔧 Как активировать workflow для автоматического запуска

## Проблема
Workflow не запускается автоматически, нужно нажимать вручную.

## Решение

### Шаг 1: Открой workflow в n8n
1. Зайди в n8n
2. Найди workflow "📊 Агрегатор статистики Instagram (1-22 января)"
3. Открой его для редактирования

### Шаг 2: Активируй workflow
1. В правом верхнем углу найди переключатель "Active" (Активен)
2. Включи его (должен быть зеленым/включенным)
3. Workflow теперь будет запускаться автоматически по расписанию

### Шаг 3: Проверь триггер
1. Убедись, что нода "⏰ Расписание (01:05 каждый день)" настроена правильно
2. Cron выражение: `5 1 * * *` (каждый день в 01:05)
3. Триггер должен быть активен (зеленая галочка)

### Шаг 4: Сохрани workflow
1. Нажми "Save" (Сохранить)
2. Workflow должен автоматически запускаться каждый день в 01:05

## Проверка

### Как проверить, что workflow активен:
1. В списке workflows должен быть зеленый индикатор рядом с названием
2. В истории выполнения должны появляться автоматические запуски
3. Проверь логи - должны быть записи о запуске в 01:05

## Если workflow все еще не запускается:

1. **Проверь настройки n8n:**
   - Убедись, что n8n запущен и работает
   - Проверь, что cron jobs включены в настройках n8n

2. **Проверь время сервера:**
   - Убедись, что время на сервере правильное
   - Cron использует время сервера, не локальное время

3. **Проверь логи n8n:**
   - Посмотри логи n8n на предмет ошибок
   - Проверь, что триггер правильно настроен

4. **Проверь права доступа:**
   - Убедись, что у workflow есть права на выполнение
   - Проверь, что нет блокировок или ограничений

## Альтернатива: Ручной запуск
Если автоматический запуск не работает, можно запускать workflow вручную:
1. Открой workflow
2. Нажми "Execute Workflow" (Выполнить workflow)
3. Workflow запустится немедленно
