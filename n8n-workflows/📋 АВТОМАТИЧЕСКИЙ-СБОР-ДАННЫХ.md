# 📋 Автоматический сбор данных за вчерашний день

## 🎯 Цель
Настроить автоматический сбор всех данных с Facebook и Instagram за вчерашний день и заполнение в Supabase.

## 📊 Какие данные собираем

### 1. Facebook (DAILY-AUTO-SYNC-01AM.json)
- **Запуск**: Каждый день в 01:00
- **Таблица**: `daily_data`
- **Поля**:
  - `spend` - Расходы (USD → KZT)
  - `impressions` - Показы
  - `clicks` - Клики
  - `leads` - Лиды (forms + conversations)
  - `followers` - Новые подписчики (из Instagram)
  - `diagnostics` - Диагностики
  - `sales` - Продажи
  - `revenue` - Выручка

### 2. Instagram Посты (INSTAGRAM-CONTENT-INTELLIGENCE-FIXED.json)
- **Запуск**: Каждый день в 01:05
- **Таблица**: `instagram_posts_stats`
- **Поля**:
  - `post_id` - ID поста
  - `caption` - Описание
  - `media_type` - Тип медиа
  - `media_url` - URL медиа
  - `posted_at` - Дата публикации
  - `impressions` - Показы
  - `reach` - Охват
  - `likes` - Лайки
  - `comments` - Комментарии
  - `shares` - Репосты
  - `saves` - Сохранения

### 3. Агрегированные метрики (INSTAGRAM-STATS-AGGREGATOR.json)
- **Запуск**: Каждый день в 01:05
- **Таблица**: `content_production_stats`
- **Поля**:
  - `publications` - Публикации (без Stories)
  - `reach` - Охват
  - `comments` - Комментарии
  - `followers` - Новые подписчики
  - `diagnostics` - Диагностики
  - `sales` - Продажи
  - `revenue` - Сумма продаж

## 🔧 Настройка Workflows

### Шаг 1: Обновить DAILY-AUTO-SYNC-01AM.json

**Проблема**: Не заполняет поле `followers` в `daily_data`

**Решение**: Добавить получение подписчиков из Instagram Insights API

1. После ноды "🔄 Обработка + Конвертация" добавить ноду для получения подписчиков
2. Обновить `jsonBody` в ноде "💾 Save to Supabase", добавив поле `followers`

### Шаг 2: Обновить INSTAGRAM-CONTENT-INTELLIGENCE-FIXED.json

**Проблема**: Фильтрует по периоду 1-22 января, а не по вчерашнему дню

**Решение**: Изменить фильтрацию на вчерашний день

1. В ноде "🔀 Merge Insights" изменить период фильтрации:
   ```javascript
   // Было:
   const periodStart = new Date('2026-01-01T00:00:00.000Z');
   const periodEnd = new Date('2026-01-22T23:59:59.999Z');
   
   // Должно быть:
   const yesterday = new Date();
   yesterday.setDate(yesterday.getDate() - 1);
   const periodStart = new Date(yesterday);
   periodStart.setHours(0, 0, 0, 0);
   const periodEnd = new Date(yesterday);
   periodEnd.setHours(23, 59, 59, 999);
   ```

### Шаг 3: Проверить INSTAGRAM-STATS-AGGREGATOR.json

**Статус**: ✅ Уже настроен правильно - собирает данные за период с 1 января по вчера

## 📝 Порядок выполнения

1. **01:00** - `DAILY-AUTO-SYNC-01AM.json`
   - Получает данные Facebook за вчера
   - Конвертирует USD → KZT
   - Сохраняет в `daily_data`

2. **01:05** - `INSTAGRAM-CONTENT-INTELLIGENCE-FIXED.json`
   - Получает посты Instagram
   - Фильтрует по вчерашнему дню
   - Получает insights для каждого поста
   - Сохраняет в `instagram_posts_stats`

3. **01:05** - `INSTAGRAM-STATS-AGGREGATOR.json`
   - Получает посты из `instagram_posts_stats` за период 1 янв - вчера
   - Получает подписчиков из Instagram Insights API
   - Агрегирует метрики
   - Сохраняет в `content_production_stats`

## ✅ Проверка

После настройки проверь:

1. **daily_data** - должны быть данные за вчерашний день
2. **instagram_posts_stats** - должны быть посты за вчерашний день
3. **content_production_stats** - должны быть агрегированные метрики за период 1 янв - вчера
