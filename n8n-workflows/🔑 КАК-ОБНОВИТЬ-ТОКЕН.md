# 🔑 КАК ОБНОВИТЬ ТОКЕН FACEBOOK

Твой токен истек? Не беда! Вот 2 способа:

---

## ⚡ СПОСОБ 1: БЫСТРЫЙ (5 минут, работает 60 дней)

### 1. Получи новый токен:

1. Открой: https://developers.facebook.com/tools/explorer/
2. **Application:** "Marketing Analytics Dashboard"
3. **Permissions** (кнопка справа):
   - ✅ `ads_read`
   - ✅ `ads_management`
   - ✅ `business_management`
   - ✅ `pages_show_list`
   - ✅ `instagram_basic`
   - ✅ `instagram_manage_insights`
4. Нажми **"Generate Access Token"**
5. Скопируй токен

### 2. Продли до 60 дней:

1. Открой: https://developers.facebook.com/tools/debug/accesstoken/
2. Вставь токен
3. Нажми **"Extend Access Token"**
4. Скопируй **НОВЫЙ Long-Lived Token**

### 3. Замени в n8n:

#### Вариант A: Прямо в JSON файле

1. Открой `n8n-workflows/DAILY-AUTO-SYNC-01AM.json`
2. Найди строку 69:
   ```json
   "name": "access_token",
   "value": "СТАРЫЙ_ТОКЕН_ЗДЕСЬ"
   ```
3. Замени на:
   ```json
   "name": "access_token",
   "value": "ТВОЙ_НОВЫЙ_ТОКЕН"
   ```
4. Сохрани файл
5. В n8n: удали старый workflow → импортируй обновленный

#### Вариант B: В n8n UI

1. Открой n8n
2. Открой workflow **"DAILY-AUTO-SYNC-01AM"**
3. Найди node **"📱 Facebook (вчера)"**
4. Нажми на него
5. В **Query Parameters** → найди `access_token`
6. Замени на новый токен
7. **Save** workflow

---

## 🏆 СПОСОБ 2: ЛУЧШИЙ (System User Token - БЕССРОЧНЫЙ!)

⚠️ **Нужен доступ к Facebook Business Manager как Админ!**

### 1. Создай System User:

1. Открой: https://business.facebook.com/settings/
2. **Users** → **System Users** (слева в меню)
3. Нажми **"Add"** (синяя кнопка справа вверху)
4. **Name:** "n8n-automation" (любое название)
5. **System user role:** Admin
6. Нажми **"Create System User"**

### 2. Дай доступ к Ad Account:

1. Нажми на созданного System User
2. Внизу найди **"Add Assets"**
3. Выбери **"Ad Accounts"**
4. Найди свой Ad Account: **"act_1005197113823722"**
5. Поставь галочку
6. **Permissions:** Admin
7. Нажми **"Save Changes"**

### 3. Генерируй бессрочный токен:

1. Нажми на System User
2. Нажми **"Generate New Token"**
3. **App:** "Marketing Analytics Dashboard"
4. **Permissions:**
   - ✅ `ads_read`
   - ✅ `ads_management`
   - ✅ `business_management`
5. **Token Expiration:** ✅ **NEVER EXPIRES** (выбери это!)
6. Нажми **"Generate Token"**
7. **СКОПИРУЙ И СОХРАНИ** токен (больше не увидишь!)

### 4. Замени в n8n (как в Способе 1)

---

## ✅ ГОТОВО!

Теперь токен будет работать:
- **Способ 1:** 60 дней
- **Способ 2:** ВЕЧНО! ♾️

---

## 🔄 Когда снова истечет (Способ 1):

1. n8n покажет ошибку: `Session has expired`
2. Повтори Способ 1 или сделай Способ 2 (один раз навсегда!)
