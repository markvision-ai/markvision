# 📸 Instagram Content Intelligence - Инструкция

## 🎯 Что делает этот workflow:

1. **Ежедневно в 01:05** автоматически запускается
2. Получает **последние 20 постов** из твоего Instagram
3. Для каждого поста получает **метрики**:
   - Показы (impressions)
   - Охват (reach)
   - Лайки (likes)
   - Комментарии (comments)
   - Репосты (shares)
   - Сохранения (saves)
4. Для каждого поста считает **бизнес-метрики** из Supabase:
   - Количество лидов
   - Количество оплаченных лидов
   - Выручка (в тенге, БЕЗ КОПЕЕК!)
5. Сохраняет всё в таблицу `instagram_posts_stats`

```sql

-- Файл: supabase/migrations/20260123210000_add_post_id_to_leads.sql
```

### 2️⃣ Импортируй workflow в n8n:

1. Открой n8n
2. Нажми **"+ Create New"** → **"Import from File"**
3. Выбери файл: `n8n-workflows/INSTAGRAM-CONTENT-INTELLIGENCE.json`
4. Нажми **"Import"**

### 3️⃣ Активируй workflow:

1. Открой импортированный workflow
2. Нажми переключатель **"Active"** (вверху справа)
3. Готово! ✅

## 📊 Как это работает:

### Пример workflow:

```
⏰ 01:05 → 📸 Получить посты → 📊 Получить метрики → 💾 Запросить лиды → 🧮 Посчитать выручку → 💾 Сохранить
```

## 🔗 Связь с лидами:

### Как заполнять `post_id` в CRM:

Когда создаешь лид вручную или через форму:
1. Скопируй ID поста из Instagram (из ссылки)
2. Вставь в поле `post_id` в CRM
3. Workflow автоматически привяжет лид к посту

### Формат post_id:

```
Ссылка поста: https://www.instagram.com/p/ABC123XYZ/
Post ID: ABC123XYZ
```

Или используй полный ID из API:
```
17841234567890123
```

## ⚠️ Troubleshooting:

### Ошибка: "Invalid access token"

**Решение:**
1. Токен истек (через 3 месяца)
2. Получи новый (см. `🔑 КАК-ОБНОВИТЬ-ТОКЕН.md`)
3. Замени в node **"📸 Get IG Posts"** и **"📊 Get Insights"**

### Ошибка: "Unsupported get request"

**Решение:**
- У поста нет insights (это нормально для старых постов)
- Workflow автоматически поставит 0

### Нет данных в таблице

**Проверь:**
1. Workflow активен? (зеленый переключатель)
2. Выполни миграции SQL?
3. Токен правильный?
4. В Instagram есть посты?

## 📅 Расписание:

- **01:00** - Загрузка данных Facebook Ads
- **01:05** - Загрузка данных Instagram Content ← **ВОТ ЭТО!**

Почему 01:05? Чтобы не перегружать API одновременно с Facebook workflow.

## 🔄 Обновление данных:

Workflow обновляет данные **каждый день**.

Если пост уже есть в таблице:
- Метрики обновятся (impressions, reach, likes и т.д.)
- Лиды пересчитаются
- Выручка пересчитается
