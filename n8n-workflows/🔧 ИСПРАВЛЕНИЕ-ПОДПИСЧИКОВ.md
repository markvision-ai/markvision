# 🔧 Исправление получения подписчиков

## ✅ Что исправлено

### 1. Добавлен параметр `metric_type=total_value`
- **Нода**: "👥 Получить новых подписчиков"
- **Параметр**: `metric_type=total_value`
- **Причина**: Instagram API требует этот параметр для метрики `follows_and_unfollows`

### 2. Улучшена логика получения данных
- **Нода**: "🧮 Рассчитать метрики"
- **Изменения**:
  - Теперь получает данные из всех входных потоков через `$input.all()`
  - Различает данные по источникам (посты, подписчики, новые подписчики)
  - Если данные не найдены в input, пытается получить из нод через `$()`
  - Добавлена обработка разных форматов ответа для `metric_type=total_value`

## 🔍 Как проверить

### 1. Проверь параметры ноды "👥 Получить новых подписчиков"
Должны быть параметры:
- `metric`: `follows_and_unfollows`
- `metric_type`: `total_value` ✅ (новый)
- `period`: `day`
- `since`: `={{ $json.period_start_timestamp }}`
- `until`: `={{ $json.period_end_timestamp }}`

### 2. Проверь connections
Все три ноды должны быть подключены к "🧮 Рассчитать метрики":
- "🔍 Обработать ответ (посты)" → "🧮 Рассчитать метрики"
- "👥 Получить подписчиков" → "🧮 Рассчитать метрики"
- "👥 Получить новых подписчиков" → "🧮 Рассчитать метрики"

### 3. Проверь логи
В логах ноды "🧮 Рассчитать метрики" должны быть:
- `📊 ВХОДНЫЕ ДАННЫЕ:` - показывает, какие данные получены
- `📊 ДАННЫЕ О ПОДПИСЧИКАХ` - данные от "👥 Получить подписчиков"
- `📊 ДАННЫЕ О НОВЫХ ПОДПИСЧИКАХ` - данные от "👥 Получить новых подписчиков"

## ⚠️ Если ноды все еще пропускаются

### Проблема: нода "🧮 Рассчитать метрики" начинает выполнение до завершения нод подписчиков

**Решение**: В n8n, когда несколько нод подключены к одной ноде, они выполняются параллельно, но нода-получатель может начать выполнение, как только получит данные от первого источника.

**Варианты исправления**:

1. **Использовать Wait node** (если доступен в вашей версии n8n)
2. **Изменить логику**: нода "🧮 Рассчитать метрики" уже использует `$()` для получения данных из нод, даже если они еще не выполнились - это должно работать
3. **Проверить, что ноды подписчиков действительно выполняются**: посмотри логи этих нод

## 📝 Формат ответа для `follows_and_unfollows` с `metric_type=total_value`

Может быть два формата:

### Формат 1: Массив значений
```json
{
  "data": [{
    "name": "follows_and_unfollows",
    "values": [
      {
        "value": {
          "follows": 10,
          "unfollows": 2
        },
        "end_time": "2026-01-23T00:00:00+0000"
      }
    ]
  }]
}
```

### Формат 2: Одно значение (total_value)
```json
{
  "data": [{
    "name": "follows_and_unfollows",
    "value": {
      "follows": 10,
      "unfollows": 2
    }
  }]
}
```

Код обрабатывает оба формата.

   - Открой workflow в n8n
   - Проверь, что есть стрелки от "👥 Получить подписчиков" и "👥 Получить новых подписчиков" к "🧮 Рассчитать метрики"

4. **Проверь, что ноды подписчиков выполняются**:
   - В истории выполнения workflow должны быть записи о выполнении этих нод
   - Если ноды не выполняются, проверь их connections
