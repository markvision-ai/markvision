# ✅ ОКОНЧАТЕЛЬНОЕ ИСПРАВЛЕНИЕ

## Что было исправлено:

### ❌ Старая логика (проблемная):
1. Нажимаешь "Отключить" → токен **удаляется** из базы
2. Нажимаешь "Привязать" заново → OAuth **не даёт токен**
3. Результат: интеграция сбрасывается, токен теряется

### ✅ Новая логика (работает навсегда):
1. **Токен НИКОГДА не удаляется** из базы
2. Кнопка "Деактивировать" → меняет `status` на `inactive`
3. Кнопка "Активировать" → меняет `status` обратно на `active`
4. **Профили всегда доступны**, даже после "деактивации"

## Преимущества:

✅ **Токен сохраняется навсегда** - не теряется при "отключении"
✅ **Быстрая активация** - одна кнопка вместо OAuth flow
✅ **Профили загружаются** - всегда, пока токен валиден
✅ **Нет путаницы** - понятно, что токен есть и можно активировать

## Если токен устареет (через 60 дней):

1. Получи новый токен в Graph API Explorer
2. Обнови в базе через SQL:
```sql
UPDATE public.ad_accounts 
SET access_token = 'НОВЫЙ_ТОКЕН'
WHERE project_id = '64c94e87-630c-470e-8ab1-8f7c8c835efa' 
  AND platform = 'facebook';
```
3. Нажми "🔄 Обновить" на странице
