# 📁 Инструкция: Добавление видео для каждого проекта

## Путь для хранения видео в Supabase Storage

### Структура папок:
```
project-videos/
  └── {project_id}/
      └── {video_filename}.mp4
```

### Примеры путей:
- `project-videos/64c94e87-630c-470e-8ab1-8f7c8c835efa/intro-video.mp4`
- `project-videos/64c94e87-630c-470e-8ab1-8f7c8c835efa/hero-video.mp4`

## Как добавить видео через Supabase Dashboard

1. Откройте Supabase Dashboard: https://supabase.com/dashboard
2. Выберите ваш проект
3. Перейдите в **Storage** (левое меню)
4. Создайте bucket `project-videos` (если его нет):
   - Нажмите "New bucket"
   - Имя: `project-videos`
   - Public: ✅ (если нужно публичный доступ) или ❌ (если нужны signed URLs)
5. Загрузите видео:
   - Откройте bucket `project-videos`
   - Создайте папку с ID проекта (например: `64c94e87-630c-470e-8ab1-8f7c8c835efa`)
   - Загрузите видео в эту папку

## Как получить URL видео в коде

### Вариант 1: Публичный bucket
```typescript
const videoUrl = `${SUPABASE_URL}/storage/v1/object/public/project-videos/${projectId}/video-name.mp4`;
```

### Вариант 2: Signed URL (рекомендуется для приватных видео)
```typescript
const { data } = await supabase.storage
  .from('project-videos')
  .createSignedUrl(`${projectId}/video-name.mp4`, 3600); // 1 час

const videoUrl = data.signedUrl;
```

## Где использовать видео в проекте

1. **Landing Page** - hero-видео
2. **Onboarding** - видео-инструкции
3. **Content Factory** - примеры контента
4. **Creative Center** - библиотека видео

## Пример кода для загрузки видео

```typescript
const uploadProjectVideo = async (projectId: string, file: File) => {
  const filePath = `${projectId}/${file.name}`;
  
  const { error } = await supabase.storage
    .from('project-videos')
    .upload(filePath, file);
  
  if (error) throw error;
  
  // Получить URL
  const { data } = await supabase.storage
    .from('project-videos')
    .createSignedUrl(filePath, 3600);
  
  return data.signedUrl;
};
```

## Важно

- Максимальный размер файла: зависит от настроек Supabase (обычно 50MB)
- Поддерживаемые форматы: `.mp4`, `.webm`, `.mov`
- Рекомендуемый формат: `.mp4` (H.264)
- Для больших видео используйте CDN или внешнее хранилище
