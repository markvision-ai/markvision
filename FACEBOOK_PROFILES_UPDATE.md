# ✅ Обновление: Отображение профилей Facebook & Instagram

## Что добавлено

### 📱 Автоматическая загрузка профилей
После подключения Facebook теперь **автоматически загружаются**:
1. **Facebook Personal профиль:**
   - Фото профиля
   - Имя пользователя
   
2. **Instagram Business аккаунты:**
   - Фото профиля
   - Username (@username)
   - Все подключенные бизнес-аккаунты

### 🔄 Кнопка "Обновить"
Добавлена кнопка для ручного обновления профилей:
- Если токен устарел - можно попробовать обновить
- Если не загрузились с первого раза
- Если добавили новый Instagram аккаунт

### ⚠️ Индикатор проблем
Если профили не загружаются, показывается предупреждение:
```
⚠️ Профили не найдены. Возможно, токен устарел.
```

## Технические детали

### API эндпоинты используются:
1. **Facebook Profile:**
   ```
   GET /me?fields=id,name,picture
   ```

2. **Facebook Pages:**
   ```
   GET /me/accounts?fields=id,name,instagram_business_account
   ```

3. **Instagram Business:**
   ```
   GET /{ig-id}?fields=id,username,profile_picture_url
   ```

### Права доступа требуются:
- ✅ `pages_show_list` - для списка страниц
- ✅ `instagram_basic` - для основной информации Instagram
- ✅ `pages_read_engagement` - для бизнес-аккаунтов

## Возможные проблемы

### Проблема: "Профили не найдены"
**Причина:** Токен устарел или нет прав доступа

**Решение:**
1. Проверь токен в Graph API Explorer: https://developers.facebook.com/tools/debug/accesstoken/
2. Если истёк - получи новый токен (он в файле `GET_FACEBOOK_TOKEN.md`)
3. Обнови токен в базе через SQL

### Проблема: Instagram не показывается
**Причина:** Нет подключенного Instagram Business аккаунта к Facebook Page

**Решение:**
1. Открой Facebook Business Suite
2. Подключи Instagram Business аккаунт к своей странице
3. Нажми "🔄 Обновить" в интерфейсе

### Проблема: CORS ошибка
**Причина:** Graph API блокирует запросы с localhost

**Решение:**
Это не проблема в production (markvision-alpha.vercel.app). 
На локалхосте используй токен из SQL напрямую.
