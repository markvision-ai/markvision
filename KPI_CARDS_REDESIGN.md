### 1. 📖 Улучшение читаемости плана

**До:**
```

```

**После:**

## 🔧 Технические детали

### Функция formatPlanValue

```tsx
const formatPlanValue = (value: number, format: 'number' | 'currency' | 'percent'): string => {
  if (format === 'currency') {
    // БЕЗ валюты ₸
    if (value >= 1000000) {
      return (value / 1000000).toFixed(1).replace('.0', '') + ' млн';
    }
    return new Intl.NumberFormat('ru-RU').format(Math.round(value));
  }
  
  if (format === 'percent') {
    return value.toFixed(1) + '%';
  }
  
  if (value >= 1000000) {
    return (value / 1000000).toFixed(1).replace('.0', '') + ' млн';
  }
  
  return new Intl.NumberFormat('ru-RU').format(Math.round(value));
};
```

**Использование:**
```tsx
// Основная цифра (С валютой):
{formatValue(value, format)}  // → "150 000 ₸"

// План (БЕЗ валюты):
{formatPlanValue(plan, format)}  // → "100 000"
```

### Badge для процента

```tsx
<Badge 
  variant={percentage >= 100 ? "default" : "secondary"}
  className={cn(
    "text-xs font-bold whitespace-nowrap px-2 py-0.5",

    percentage < 100 && "bg-muted text-muted-foreground"

  {percentage.toFixed(0)}%
</Badge>
```

**Варианты:**
- `percentage >= 100`: зеленый Badge
- `percentage < 100`: серый Badge
