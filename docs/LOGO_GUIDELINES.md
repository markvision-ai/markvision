# MarkVision AI - Руководство по использованию логотипа

## 1. Введение

Этот документ описывает правила использования логотипа MarkVision AI для обеспечения визуальной целостности бренда на всех платформах и носителях.

## 2. Основной логотип

Логотип MarkVision AI состоит из двух элементов:
1.  **Графический знак (Символ):** Стилизованная буква "M", выполненная в виде нейронной сети с узлами (nodes) и связями, и стрелкой роста, проходящей сквозь неё снизу-вверх вправо.
2.  **Текстовая часть (Логотип):** Название "MarkVision AI", набранное фирменным шрифтом.

### Цветовая схема

Логотип использует фирменный градиент:
*   **Start (Blue-500):** #3b82f6 (RGB: 59, 130, 246)
*   **Middle (Violet-500):** #8b5cf6 (RGB: 139, 92, 246)
*   **End (Cyan-500):** #06b6d4 (RGB: 6, 182, 212)

**Фон:**
*   Предпочтительный фон: **Deep Dark (#030303)**.
*   Допустимый фон: Белый (#ffffff) или светлый нейтральный.

## 3. Размеры и масштабирование

Логотип разработан в векторном формате (SVG) и масштабируется без потери качества.

### Минимальные размеры
*   **Favicon:** 16x16px (упрощенная версия без мелких деталей, только основные линии)
*   **Web Icon:** 32x32px
*   **App Icon:** 44x44px (iOS min touch target)
*   **Print:** 10mm ширина.

### Рекомендуемые размеры
*   **Header:** 32-40px высота знака.
*   **Footer:** 40-64px высота знака.
*   **Splash Screen:** 128px+

## 4. Охранное поле (Clear Space)

Вокруг логотипа должно быть свободное пространство, равное высоте буквы "M" в знаке, чтобы обеспечить его читаемость и визуальную независимость от других элементов.

## 5. Недопустимое использование

*   ❌ Не искажать пропорции (растягивать/сжимать).
*   ❌ Не менять цвета градиента на произвольные.
*   ❌ Не поворачивать логотип (кроме анимации загрузки, если применимо к отдельным элементам).
*   ❌ Не использовать на пестром фоне, затрудняющем чтение.
*   ❌ Не добавлять тени (drop shadow), если это не предусмотрено стилем (например, "Neon Glow" на темном фоне).

## 6. Техническая реализация (Web)

Логотип реализован как React-компонент `MarkVisionLogo.tsx`.

```tsx
import { MarkVisionLogo } from '@/components/ui/MarkVisionLogo';

// Иконка 64px
<MarkVisionLogo size={64} />

// Полная версия с текстом
<MarkVisionLogo variant="full" className="h-10" />
```

Для использования в `img` тегах или внешних ресурсах используйте SVG экспорт или генерацию PNG из Figma/Illustrator на основе предоставленного SVG-кода.

## 7. Печать (CMYK)

Для печатных материалов используйте следующие приближенные значения CMYK для градиента:
*   Blue: 70/35/0/0
*   Violet: 60/60/0/0
*   Cyan: 60/0/10/0

*Рекомендуется использовать векторные форматы (EPS, PDF) для печати.*
