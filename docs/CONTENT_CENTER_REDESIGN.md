# Центр контента: редизайн и архитектура

## Задачи
- Визуализация всех этапов производства: идеи → сценарии → генерация → дистрибуция
- Реалтайм‑дашборд текущих операций (обновление каждые 30s)
- Интерактивная карта процесса (агрегированные метрики, прогресс)
- Фильтры и поиск по линиям, статусы и уведомления
- Экспорт отчётов (CSV)
- Адаптивная вёрстка

## Архитектура UI
- Контейнер страницы: ContentFactoryPage → ContentFactoryV4
- Зоны:
  - IdeasHeader (входящий поток)
  - ScriptWorkshop (сценарии)
  - CreationCenter (производственные линии, прогресс)
  - PostingDashboard (очередь публикаций)
  - OperationsPanel (реалтайм‑операции, поиск/фильтр)
  - ProcessMap (интерактивная карта процесса)
  - ExportReportButton (CSV)

## Реалтайм
- setInterval 30s в OperationsPanel для обновления рендера
- Симуляция прогресса в store; подключение к внешним источникам возможно через замену действий в store

## Уведомления
- Toast при переходе линии в состояния ready/error (эффект в ContentFactoryV4)

## Производительность
- Ленивая визуализация, простые вычисления агрегатов
- Адаптивная сетка (1–2 колонки для панелей)

## Дальнейшее
- Подписки на реальные события (webhooks)
- Экспорт в XLSX/PDF и авторассылка
