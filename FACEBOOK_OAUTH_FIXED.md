## 🚀 Как использовать (ПРОСТАЯ ЛОГИКА):

### Шаг 1: Нажми "Привязать аккаунт"
```
Кнопка: "Привязать аккаунт" (с логотипом Meta)
```

### Шаг 2: Окно Facebook откроется
- ✅ Выбери Business Manager
- ✅ Выбери Fan Page
- ✅ Выбери Рекламный кабинет
- ✅ Нажми "Подключить"

### Шаг 3: Готово! ✅
```
✅ Facebook подключен!
✅ Отображается твой профиль
✅ Отображается Instagram аккаунт (если есть)
✅ Данные автоматически загружаются
```

---

## 📊 Что произойдет автоматически:

1. **Токен сохраняется** в Supabase (таблица `ad_accounts`)
2. **Профиль загружается** (Facebook + Instagram)
3. **Статус меняется** на "Активно" ✅
4. **Кнопки появляются:**
   - 🔄 Обновить (перезагрузить профили)
   - ⏸️ Деактивировать (отключить без удаления токена)

---

## 🔄 Если токен истек:

### Автоматически:
```
1. Ошибка "Session has expired" перехватывается
2. Статус меняется на "inactive"
3. Кнопка меняется на "Привязать аккаунт"
```

### Что делать:
```
Просто нажми "Привязать аккаунт" заново!
Все разрешения запросятся автоматически.
```

## 🆘 Troubleshooting:

### Ошибка: "Facebook SDK не загружен"
**Решение:** Перезагрузи страницу (Ctrl+R / Cmd+R)

### Ошибка: "Session has expired"
**Решение:** Нажми "Привязать аккаунт" заново

### Профиль не отображается
**Решение:** Нажми кнопку "🔄 Обновить"

### Токен не сохранился
**Решение:** 
1. Открой консоль (F12)
2. Проверь ошибки
3. Попробуй снова
